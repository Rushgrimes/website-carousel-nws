## Current implementation notes

- Fixed Rush weather uses Open-Meteo; the earlier NWS requirement was superseded because NWS does not serve Ireland.
- The Open Waters public stream can be used without the personal key. A connected but empty feed is a valid outcome; no markers should appear until real reports arrive.
- Live Overpass or AIS coverage depends on network/provider availability, so the page must retain clear fallback and unavailable states.
- The repository owner later explicitly authorized public visibility and GitHub Pages publication. Do not treat that authorization as permission to reveal credentials or use the private AIS key in client code.
